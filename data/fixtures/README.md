# Public foundation sample

Only [OpenJLPT](https://github.com/evanclan/OpenJLPT/tree/0d1d3410bec90bd4098a7c72de820543cb4f707c),
commit `0d1d3410bec90bd4098a7c72de820543cb4f707c`, is included:
8 N5 vocabulary records, 4 N5 kanji, 3 N5 grammar records and the grammar examples.
The sample preserves Japanese/English content. Vocabulary examples are omitted;
no Vietnamese translation or external dictionary has been inserted.

This selection/serialization is distributed under **CC BY-SA 4.0**.
Credit OpenJLPT contributors, EDRDG (JMdict and KANJIDIC2), and Jonathan Waller's
JLPT lists. See the complete `LICENSE.OpenJLPT.txt` and `NOTICE.OpenJLPT.md` here
for the upstream attributions and license links. Grammar examples are authored
by OpenJLPT contributors. No Tatoeba vocabulary examples are included in this subset.

The generated SQLite database is local and gitignored. Seeding refuses to overwrite
an existing database. Test-only synthetic translations are created in isolated test
databases and are not part of this content sample.
